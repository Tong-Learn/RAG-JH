# 样例（examples）

本项目的处理对象是 **《晶核》游戏官方更新公告**（真实语料）。本目录附带了 **3 份公告**：
- `pdf/` —— **3 份抽样源 PDF**（`9月2日`、`8月19日`、`11月26日` 更新公告），可直接运行；
- 每份公告经管线加工后的**三个产物**（见下），绕开"全量 54 份语料"的体积，便于看清「结构感知」链路的数据形态。

> 完整源语料 `test/`（54 份 PDF，约 125.4MB）**不纳入版本控制**（版权+体积），仅本地运行用；
> 这里的 3 份是**抽样、可直接运行**的例外，用于复现一个 mini 闭环。

## 样例清单

每个公告对应三个产物，分别对应管线的不同阶段：

| 文件后缀 | 阶段 | 说明 |
|---|---|---|
| `*_extracted.md` | ① 数据准备（人工核对） | 管线从 PDF 提取并清洗后的**可读文本**，用于人工确认结构是否正确 |
| `*_blocks.jsonl` | ① 数据准备（中间表示） | **Block 语义中间表示** `{kind, text, ...}`，`kind ∈ {heading, para}` |
| `*_chunks.jsonl` | ③ 结构感知切片 | 切片产物 `{id, doc, section_path, text, rows, start_block, end_block}` |

选取的三份公告（均已按**标题修复后**的管线刷新，能直接看到「常规服 / 赛季服」这类标题被完整合并、不再割裂）：
- `9月2日更新公告丨常规服团本活动开启 赛季服强化突破功能上线` —— 含「常规服」「赛季服」两个分节标题，**直接展示标题（含跨 baseline 抖动的散落字形）被完整还原**；正文带页码溯源。
- `8月19日更新公告丨PVP玩法平衡调整 艾尔莎转职限制解除` —— 篇幅较小、含标题栈层级（`section_path`），展示小节切分与标题合并。
- `11月26日更新公告丨冒险传承系统开启 矿战新赛季载具揭晓` —— 标准公告样例，展示标题栈 / 段落 / 溯源坐标。

## 数据形态速览

**Block（`*_blocks.jsonl`，以 `9月2日…` 为例：16 heading + 20 para）**
```json
{"kind": "heading", "text": "常规服"}
{"kind": "heading", "text": "赛季服"}
```

**Chunk（`*_chunks.jsonl`，以 `9月2日…` 为例：第 1 个 chunk）**
```json
{"id": "chunk_000001",
 "doc": "9月2日更新公告丨常规服团本活动开启 赛季服强化突破功能上线",
 "section_path": ["9月2日更新公告丨常规服团本活动开启 赛季服强化突破功能上线", "常规服"],
 "text": "9月2日更新公告丨常规服团本活动开启 赛季服强化突破功能上线 > 常规服\n亲爱的冒险者：……",
 "rows": [], "start_block": 2, "end_block": 5, "start_page": 1, "end_page": 1}
```

> id 说明：`chunker` 的计数器「先自增再用」，故首个 id 为 `chunk_000001`（全局 id 从 1 起，0 不使用）。

`section_path` 为**完整标题路径**（如 `[公告名] > 常规服`），命中后凭 `doc + section_path + start/end_block(+start/end_page)`
即可**回溯回原文 + 页码**，实现「附原文链接」。

## 局限（如实说明）

- 本公告语料的解析产物 **只有 `heading` / `para` 两种 Block，没有 `table`** —— 原因是**这些公告本身不含真表格**。
  注意：`page.find_tables()` 会**误报**（实测把「团战挑战规则调整」等**板块标题**误报成 1×1 的"表格"），
  已由 `_is_fake_table()`（**单行/单列 → 判为误判**）拦截；误报区域的短文本转成 `heading` 候选，故最终不产生 `table` 块
  （判定规则见 `docs/数据准备方案.md`）。
- `table` 是管线的**通用能力**，但本批语料无真表，需另用**含真表格**的文档验证。
- 对**无结构 / 多栏混排 / 扫描件（无文本层）**的文档，需调整解析与切片策略；本管线面向「单份公告型、有文本层」的文档。

## 重复说明

- 全量结果：54 份公告 → **605 chunk** → chroma 605 行（cosine）。此处仅节选 3 份作样例（含源 PDF）。
- 目录本身**受版本控制**（不像 `test/`、`data/chroma|processed|chunks` 那样被 `.gitignore` 忽略）。
