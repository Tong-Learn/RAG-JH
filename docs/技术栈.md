# 技术栈（Tech Stack）

> 从零实现的 RAG 管线，处理对象为《晶核》游戏官方更新公告 PDF。统一运行环境：`.venv_rag311`（Python 3.11）。

## 语言 / 运行时

- **Python 3.11**（`.venv_rag311`）—— `chroma-hnswlib` 官方 Windows wheel 仅提供到 cp311。

## 文档解析（数据准备）

- **PyMuPDF (`fitz`)** —— PDF 提取：文本层 + 字号/加粗 + `find_tables()`。
  本项目**只处理 PDF**（源语料 54 份全为 PDF），故仅此一个解析库。

## 向量化 / 向量库

- **DashScope** `qwen3.7-text-embedding-flash`（**1024 维**）—— 嵌入走 OpenAI 兼容接口
  （`POST /compatible-mode/v1/embeddings`）；模型名可经环境变量 `DASHSCOPE_EMBEDDING_MODEL` 配置。
- **chromadb 0.6.3** + **chroma-hnswlib 0.7.6** —— 持久化向量库，`hnsw:space=cosine`；集合名 `rag_chunks`。
- **numpy 1.26.4**、**requests**。

## 检索

- **BM25**（`rank_bm25`）+ **jieba** 分词 —— 关键词/精确词检索，补向量对专名、数字、版本号的短板。
- **混合检索**（`retrieval/hybrid.py`）—— BM25 与向量以 **RRF（Reciprocal Rank Fusion，k=60）** 融合。
  选 RRF 而非加权求和：它基于**排名**而非分数，天然规避两种分数尺度不可比的问题。
- **重排**（`retrieval/reranker.py`）—— DashScope `qwen3.7-text-rerank`，对候选重排后取 top-k。
  选 API 而非本地 reranker：本机 `torch` / `onnxruntime` 存在 DLL 加载失败与崩溃问题。

## 生成

- **DashScope chat**（默认 `qwen3.8-max`，可 `--model` 覆盖）—— 生成带引用回答，走 OpenAI 兼容
  `chat/completions`。
- **阈值拒答** —— top-1 分数低于该路线阈值即拒答，**不调用生成 API**。两条路线分数尺度不同，
  各配一个阈值：纯向量 `0.55`、混合+重排 `0.58`（数字见 `metrics.json`，校准脚本 `scripts/calibrate_threshold.py`）。

## 关键依赖

- 直接依赖及版本锁定说明见 `requirements.txt`。
- `chromadb 0.6.3` 的传递依赖需 `numpy < 2`。

## 刻意排除（因故障或环境约束）

- `torch` / `onnxruntime`（Python 3.13 下 DLL 加载失败）、`sentence_transformers`（依赖 torch）、
  `chromadb ≥ 1.5`（Rust 绑定段错误）、本地 `hnswlib`（未安装）。
- 境外网络（HuggingFace / OpenAI / PyPI）不可达 → 改用国内服务（DashScope + 阿里云 PyPI 镜像）。

## 工程约定

- chromadb 显式配置 `Settings(anonymized_telemetry=False)`。
- 统一在 `.venv_rag311` 下运行；脚本以 `python -m scripts.xxx` 方式调用。
