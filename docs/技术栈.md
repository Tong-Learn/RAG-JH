# 技术栈（Tech Stack）

> 从零实现的 RAG 管线。统一运行环境：`.venv_rag311`（Python 3.11）。版本锁定的**原因与故障**见 `docs/故障报告.md`。

## 语言 / 运行时
- **Python 3.11**（`.venv_rag311`）。原因：`chroma-hnswlib` 官方 Windows wheel 仅到 cp311。

## 文档解析（数据准备）
- **PyMuPDF (fitz)** `1.28.x` —— PDF 提取（文本层 + 字号/加粗 + `find_tables()`）。
- **python-docx** —— Word（标题样式 + 原生 Table）。
- **openpyxl** —— Excel（行列读取）。
- **python-pptx** —— PPT（标题/表格/文本框）。
- **标准库** —— txt / md。

## 向量化 / 向量库
- **DashScope（阿里云千问）** `qwen3.7-text-embedding`（1024 维，默认；额度不足回退 `qwen3.7-text-embedding-flash`）—— 嵌入走 OpenAI 兼容接口（`POST /compatible-mode/v1/embeddings`），国内直连；模型名走 `DASHSCOPE_EMBEDDING_MODEL`。
- **chromadb 0.6.3** + **chroma-hnswlib 0.7.6** —— 持久化向量库，`hnsw:space=cosine`；集合 `rag_chunks`。
- **numpy 1.26.4** —— 向量运算。
- **requests** —— 调用 DashScope。

## 检索增强（2026-08）
- **BM25** `rank_bm25` 0.2.2 + **jieba** 0.42.1 —— 关键词/精确词检索，补向量对专名/数字的短板。
- **混合检索** `retrieval/hybrid.py` —— BM25 与向量用 **RRF（Reciprocal Rank Fusion, k=60）** 融合，避免分数尺度不可比。
- **重排** `retrieval/reranker.py` —— DashScope `qwen3.7-text-rerank`，对候选 top-N 重排取 top-k（走 API 而非本地，因本机 torch/onnxruntime 有崩溃前科，见 `docs/故障报告.md`）。

## 生成（End-to-end RAG）
- **DashScope chat（默认 `qwen3.8-max`，可 `--model` 覆盖）** —— 带引用回答，走 OpenAI 兼容 `chat/completions`；`--min-score` 阈值拒答（校准 0.70）。

## 关键依赖版本
- **onnxruntime 1.19.2**（锁 `<1.29`）、**posthog 3.x**（锁 `>=2.4.0,<4.0.0`）、**numpy `<2.0`**、**rank_bm25 0.2.2**、**jieba 0.42.1**、**pytest 9.1.1**（详见 `requirements.txt`）。

## 刻意排除（因为故障/约束，见 `docs/故障报告.md`）
- `torch` / `onnxruntime`（全局 Python 3.13 下 DLL 失败）、`sentence_transformers`（依赖 torch）、chromadb ≥1.5（Rust 绑定段错误）、本地 `hnswlib`（未装）。
- 国外网络（HF/OpenAI/PyPI）不可达 → 走国内服务（DashScope + 阿里云 PyPI 镜像）。

## 常用库（非核心）
- chromadb 配置显式 `Settings(anonymized_telemetry=False)`；`pymupdf_layout`（已安装，评估过「版式分析」，**未接入**，见 `docs/问题与处理记录.md` D1）。
