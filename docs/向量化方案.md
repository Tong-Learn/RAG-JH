# 向量化方案

> 管线第 ③ 步：把切片产物向量化并写入向量库，供检索阶段使用。切片本身见 `切片方案.md`。

## 1. 定位

| 项 | 内容 |
|---|---|
| 输入 | `data/chunks/*.chunks.jsonl`（每个 chunk 的 `text` 为待向量化字符串） |
| 输出 | `data/chroma`，集合 `rag_chunks` |
| 代码 | `embedding/dashscope_embedder.py`（嵌入封装）、`scripts/run_vectorize.py`（入库编排） |

## 2. Embedding 模型

| 项 | 取值 |
|---|---|
| 模型 | DashScope `qwen3.7-text-embedding-flash`（默认；可经 `DASHSCOPE_EMBEDDING_MODEL` 覆盖） |
| 维度 | **1024** |
| 接口 | `POST /compatible-mode/v1/embeddings`（OpenAI 兼容），`Authorization: Bearer <key>` |
| 批量 | 单请求 ≤ 10 行（`MAX_BATCH`），默认 `batch_size=8` |
| 失败处理 | 单批重试最多 3 次（退避 1.5×(n+1) 秒）；超长输入交由服务端按自身 token 上限处理/报错，**不做静默截断** |

## 3. 向量库与入库

- **chromadb 0.6.3** + **chroma-hnswlib 0.7.6**，`hnsw:space=cosine`（distance 0 = 完全一致）。
- **幂等重建**：每次运行先 `delete_collection` 再 `create_collection`。
  （`delete(where={})` 在 0.6.3 不会清空集合，故不用它做清库。）
- **batch_size 规避**：`hnsw:batch_size = max(1000, len(chunks) + 10)`。
  原因：Windows 下 hnsw 索引跨过 batch 边界时 `add()` 会 `0xC0000005` 崩溃（无 traceback）；
  把该值调到大于本次入库总数，可让单次入库不触发边界刷新。

### chunk → chromadb 行映射

| chromadb 字段 | 来源 |
|---|---|
| `id` | `chunk.id`（如 `chunk_000023`） |
| `document` | `chunk.text` |
| `metadata` | `doc` / `section_path` / `start_block` / `end_block` / `start_page` / `end_page` |

说明：metadata 只接受标量，故 `section_path`（列表）拍平为 `" / "` 连接的字符串。
命中后用 `id` 回映射到原 chunk，再凭 `doc + section_path + start/end_block(+page)` 回溯原文与页码。

## 4. 运行

```powershell
.venv_rag311\Scripts\python.exe -m scripts.run_vectorize
```

需 `.env` 提供 `DASHSCOPE_API_KEY`（`.env` 已加入 `.gitignore`）。

## 5. 运行约束

- **升级 chromadb 前必须回归**：`1.5.x`（Rust/PyO3 绑定）在本机 Windows 上 `add()` 必段错误（`0xC0000005`）。
- 安装依赖需带版本约束，否则可能被拉高 `onnxruntime` 导致 import 崩溃（见 `requirements.txt`）。
- 集合名要求长度 ≥ 3 且仅含 `[a-zA-Z0-9._-]`。
- 显式配置 `Settings(anonymized_telemetry=False)`；依赖中限制 `posthog < 4`，否则 0.6.3 的旧签名调用会抛 `TypeError`（无害但干扰日志）。
- **始终显式传入 embeddings**，不依赖 chromadb 默认 ONNX 嵌入函数（避免额外下载与依赖问题）。

## 6. 已知限制

- **模型或维度变更后旧库不可混用**：必须全量重建。`run_vectorize` 每次都是幂等重建，天然满足此要求。
- **基于分数的参数随模型失效**：阈值（拒答值）依赖 score 分布，换 embedding 模型后必须重新校准
  （见 `scripts/calibrate_threshold.py`），否则会出现大面积误拒。
